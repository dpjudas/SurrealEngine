\# No-AI Code Rule



\## Purpose

\* \*\*Ban automated generation\*\*: No AI tools (like Copilot or ChatGPT) may write code.

\* \*\*Protect intellectual property\*\*: Prevent unvetted or copyrighted code from entering the codebase.

\* \*\*Encourage human skill\*\*: Ensure developers fully understand every line they write.



\## Rules

\* \*\*No AI generation\*\*: Do not use AI to write functions, scripts, or entire files.

\* \*\*No AI refactoring\*\*: Do not let AI rewrite or clean up existing code blocks.

\* \*\*Manual debugging\*\*: Fix bugs and errors using human knowledge and standard debugging tools.



\## Exceptions

\* \*\*Documentation reading\*\*: AI may summarize error logs or official docs.

\* \*\*Open-source linters\*\*: Standard, non-AI automated tools are allowed for formatting.



\## Enforcement

\* \*\*Code reviews\*\*: Reviewers will reject PRs suspected of containing AI-generated code.

\* \*\*Team checks\*\*: Violations require rewriting the code manually from scratch.
